# uP Nele & Nela

Landing page editorial do protocolo **uP Nele & Nela** da SmileSkin — rejuvenescimento íntimo masculino e feminino.

## Stack

- HTML + CSS + JavaScript vanilla (zero dependências, zero build step)
- Tipografia: Fraunces, Instrument Serif, Plus Jakarta Sans (Google Fonts)
- Paleta: petrol + ouro + creme, com variações nude-rosado (Nela) e petrol-oliva (Nele)

## Estrutura da página

- **Hero** · manifesto de entrada
- **Manifesto** · citação editorial
- **Duo** · apresentação Nele / Nela lado a lado
- **O Protocolo** · pilares técnicos
- **Idealizadores** · equipe
- **uP Nele** · protocolo masculino
- **uP Nela** · protocolo feminino
- **Antes & Depois** · slider comparativo interativo com casos clínicos ilustrativos
- **Segurança** · compromissos clínicos
- **CTA** · agendamento
- **FAQ** · dúvidas frequentes
- **Footer**

## Rodar localmente

```bash
python -m http.server 3000
# acesse http://localhost:3000/
```

## Publicar via GitHub Pages

`Settings` → `Pages` → Source: `main` / root. A página fica disponível em `https://<user>.github.io/upnele-upnela/`.

## Ética & Conformidade

As imagens do bloco *Antes & Depois* são **representações artísticas abstratas** (gradientes SVG gerados em tempo real), não fotografias clínicas. Material fotográfico real é apresentado somente em consulta presencial, mediante termo de autorização do paciente, em conformidade com o Código de Ética Médica do CFM e a LGPD.
